## 1. 为什么要重做这本手册

2025 年 9 月，我们发布了[《AI 原生应用架构白皮书》](https://developer.aliyun.com/ebook/8479)，沿着 AI 原生应用的 DevOps 全生命周期，系统拆解过架构选型与研发要点。但过去一年模型与智能体跑得太快，行业重心已经从“能不能快速搭出一个会聊天的 Agent”，变成了三座更硬的工程大山：

* **工程化挑战**：怎么让看概率说话的模型，扛起不能出差错的生产级关键任务。
* **规模化挑战**：单点 Demo 跑通不难，难的是大流量并发下依然稳、安全、跑得快、账单算得清。
* **组织化挑战**：怎么把散落各处的 Agent 孤岛接进企业核心流程，协同而不乱套。

旧版框架已经兜不住这些新问题。因此我们重构了整本书的骨架并开源长期维护，大幅提高真实一线实践的占比，帮你跳过空洞的概念宣传，直接看清架构选型和立项里的真实取舍。

## 2. 怎么用这本手册最高效

本书收录的每篇实践都经过人工审核，确保和全书统一的工程坐标系对齐。推荐两种用法：

* **人来读**：哪怕你还没搭过企业级 Agent，也可以顺着“调研现状 → 定架构 → 写脚手架 → 跑稳底座 → 管住权限 → 建评估飞轮 → 看一线案例”一条线读下来，当成一套完整的实战教材。
* **喂给你的 Agent 当知识库**：全书结构清晰、职责切分明确，非常适合按章节或专题接入内部知识库按需检索。

## 4. 下一步规划与欢迎共建

这本手册不是写完就封存的文档，而是会跟着一线工程进展持续生长的活项目。接下来的更新重点包括：

- **扩充一线真实案例**：补齐研发、运营、客服、数据、安全、财务等场景的实战复盘，不只写怎么成功，更写踩过的坑和当时怎么做取舍。
- **配套云上动手实验**：围绕沙箱、Runtime、AI 网关、状态存储、可观测和评估体系，提供可复现的实操流程，让你读完能直接上手验证。
- **深化企业级治理**：跟进身份委派、提示词注入防护、数据防泄密、资产注册发现与上线前红队仿真等硬核议题。
- **补全评估与数据飞轮**：完善任务成功率、轨迹评估、大模型裁判（LLM-as-a-Judge）、黄金数据集、Badcase 回归与灰度实验方法论。
- **紧跟底座技术演进**：持续吸收模型、Harness、MCP/A2A 协议、Runtime 与 Agentic OS 的前沿进展，及时修正已经过时的老判断。
