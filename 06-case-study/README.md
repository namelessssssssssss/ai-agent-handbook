# 实践篇导读

本篇把镜头切到企业一线和开源社区真实战场：覆盖研发效能、设计工程、运维安全与企业 IT、客户服务与运营，并收录了 2026 年 GOAI 世界人工智能开源大赛 Agent Infra 赛道的优秀工程作品。

如果你想直接按正在卡壳的问题挑案例，可以这样看：

- **研发效能（第 25 章，共 8 个案例）**：想看 AI 怎么写内核补丁测试、增强 Code Review、做运维评测，或者安全、数据库、云通信团队怎么靠多 Agent 协同改掉交付流程，直接看这里。
- **设计工程（第 26 章，共 2 个案例）**：聚焦 Vibe Designing 与 GenUI，看 Agent 如何跨过“只给一段文案或静态图片”，直接交付可用界面和结果。
- **运维、安全与企业 IT（第 27 章，共 3 个案例）**：畅捷通、吉利汽车、塔斯汀在大规模生产环境里落智能运维和故障闭环的真实取舍。
- **客户、销售与运营（第 28 章，共 4 个案例）**：MiniMax、B 站在长周期记忆和全域内容洞察上的底座实践，信永中和的办公提效探索，以及滔搏体育基于 AgentCore 与 AgentLoop 规模化运营企业级智能体的打法。
- **前沿基础设施探索（第 29 章）**：收录 2026 年 GOAI 世界人工智能开源大赛 Agent Infra 新智基座赛道的 15 项决赛作品（重点拆解 9 项代表性实践），横跨能源电力、金融、建筑设计、零售、数字内容（游戏 / XR / 电商）、企业治理、财务结算、软件工程、IT 运维、网络安全和数据工程等 11 个垂直领域。
