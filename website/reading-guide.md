# 阅读指南

这本手册只回答一个核心问题：**怎么把会聊天的模型，改造成能真干活、不出大乱子、账单可控还能持续变好的生产级 Agent 系统**。

你不用从第一页死磕到最后一页——直接对照你手头最急的工程任务挑路线就行。

## 1. 刚上手 Agent，想先把全局拼图和黑话对齐

如果你刚接触企业级 Agent，最容易被各种框架名词绕晕。建议先看行业大盘，再把 Model（大脑）、Harness（脚手架）、Runtime（长跑宿主）、Sandbox（隔离笼子）和五类信息对象的分工摸清，再看怎么把它们拼在一起。

- **推荐路径**：[2026 开发者调研报告](/survey.html) → [架构篇](/architecture/)（第 01—02 章）→ [构建篇](/build/)（第 03—06 章）→ [治理篇](/governance/)（第 13—16 章）
- **带走的核心判断**：什么时候用写死流程的 Workflow 就够了、什么时候才需要上 Agent；别把所有东西全塞进上下文窗口。

## 2. Demo 跑通了，准备推上生产扛真实流量

本地跑通一段脚本只要半小时，但一上生产就面临机器重启任务归零、命令乱执行、多人并发串数据、Token 账单爆炸。这条线专门帮你把生产底座垫稳。

- **推荐路径**：[运行篇](/run/)（重点看第 07—09 章底座与网关 → 第 10 章长任务）→ [治理篇](/governance/)（第 13—14 章观测与安全）→ [调优篇](/optimization/)（第 18—23 章）
- **带走的核心判断**：长任务的状态必须写到进程外面；Sandbox 和网关护栏必须卡在模型绕不过去的位置。

## 3. 单 Agent 搞不定，正在搭建多 Agent 协作系统

很多团队一上来就堆一堆 Agent 互相聊天，结果上下文越传越丢、互相等成死锁、出了错也不知道谁背锅。这条线先帮你想清楚“该不该拆角色”，再讲怎么拆得稳、通信不乱、出了问题查得出来。

- **推荐路径**：[第 04 章任务编排](/build/chapter-04.html) 与 [第 06 章受控行动](/build/chapter-06.html) → 运行篇的 [第 10 章异步任务](/run/chapter-10.html)、[第 11 章协作编排](/run/chapter-11.html) 与 [第 12 章分布式通信](/run/chapter-12.html) → 治理篇第 13、16 章
- **带走的核心判断**：能用一个 Agent 加清晰子任务做完的，绝不硬拆多 Agent；一旦拆了，就把任务权限租约和移交边界写死。

## 4. 负责效果评估、Badcase 收敛与持续调优

上线后天天被业务问“Agent 到底好不好用”，改了一版 Prompt 不知道是变好了还是改坏了？这条线教你丢掉“人工抽看几十条”的手工作坊，建起一套靠线上轨迹（Trace）驱动的数据飞轮。

- **推荐路径**：先看 [第 18 章 Agent 调优总览和实践](/optimization/chapter-18.html) 摸清整条飞轮怎么转 → 第 13 章采集规范 → 第 19—23 章（轨迹、清洗、黄金集、Badcase 闭环、受控自进化）→ 需要改模型权重时再进 [第 17 章模型调优](/optimization/chapter-17.html) → 对照实践篇案例
- **带走的核心判断**：别动不动先去微调模型，先把数据飞轮、评测集和 Harness 脚手架的漏洞补齐。

## 5. 负责技术选型、立项拍板或跨团队架构评审

需要判断到底自建还是买平台、业务到底值不值得上高自主性 Agent、投多少人力和算力划算？这条线帮你直接对齐业务收益、投入成本与未来演进方向。

- **推荐路径**：[开发者调研报告](/survey.html) → 架构与构建前导（第 01—03 章）→ [实践篇](/cases/)（按行业或场景对标投入与收益）→ [第 30 章从应用走向 Agentic OS](/outlook/chapter-30.html)
- **带走的核心判断**：追求“成本与风险可接受的最低充分架构”，而不是盲目追逐听起来最炫的形态。

## 6. 在线阅读小技巧

- **找章找节**：左侧栏切换全书篇章，右侧栏直跳当前章节的小节。
- **全书秒搜**：顶栏搜索框同时支持中文业务词和英文专业术语，可直接定位到具体段落。
- **断点续读**：浏览器会自动记住你读到哪一页，回首页就能一键接着看；每章末尾也有“上一篇 / 下一篇”连读入口。
- **看清大图与长表**：正文里的架构图和调研图表都支持点击放大；宽表格和代码块可以左右滑动查看。
- **个性化与共建**：支持切换明暗主题、调整字号和打印当前页；发现错漏或有更好解法，点页面反馈入口就能提 Issue 或直接参与编辑。
